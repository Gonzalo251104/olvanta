# Cambios

## 0.6.0

Consulta de disponibilidad, operación de contratos, cuotas, cargos, garantías, renovación y cobro por sucursal desde Alquileres. Acceso a la facturación de cada cuota.

## 0.5.0

Bandeja de facturación por sucursal con preparación desde ventas, notas, resúmenes, bajas, descargas de archivos y consulta del historial de envío.

## 0.4.0

Cotizaciones, pedidos, ventas, cobros parciales, reembolsos y arqueos desde Comercial. Documentos y cierres imprimibles.

## 0.3.0

Compras e inventario por sucursal. La web permite preparar compras, recibir partidas, operar almacenes y consultar saldos, lotes y el historial de movimientos con la API 0.3.0.

## 0.2.0

Acceso de operadores, administración, selección de sucursal, catálogo y fichas de clientes y proveedores sobre la API 0.2.0. Estado técnico en /estado.

## 0.1.0

Pantalla de estado en español, actualización manual y cliente generado para el contrato Olvanta API 0.1.0.
